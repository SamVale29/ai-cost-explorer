## Additional corrections discovered during M7 review

- GPT-5.6 Terra and Luna pricing moved to their current official model pages. Standard short-context input/output are $2/$12 and $0.20/$1.20, respectively. Published long-context and cache-write multipliers are applied; long-context cached input remains unknown because its multiplier is not explicit on these pages. Previous observations are preserved.
- Mistral prices match the current labeled inference pricing table. Pricing provenance now points to that table; model cards continue to provide model documentation. This avoids trying to infer input/output semantics from unlabeled visual cards.
- Together's former inference pricing URL redirects to an overview. Qwen3.6 Plus standard pricing is verified in the current model table; unsupported model-specific batch rates are now unknown.
- DeepSeek's direct V4 Flash alias now serves V4.1 Flash. The historical direct offer is retired in this catalog. DeepSeek V4 Pro rates are stored separately as `peak` and `off-peak`. The calculator explicitly declines to produce a time-of-use total without a schedule; both rates and the official schedule are visible in model details.
- The catalog contains 48 offers, 29 registered sources and 16 dated history events. README/methodology counts were corrected.
- Pages deployment now runs the reusable quality workflow against the same commit before artifact upload/deployment.

## Verification and limits

Local checks: data validation, source URL registry, model coverage, benchmark contract, TypeScript, ESLint, formatting, 75 unit/UI tests, production build and static HTTP route checks. Dependency audit found no known vulnerabilities. Browser tests run in GitHub CI; local Chromium installation was unavailable in this environment, so local browser success is not claimed.

The live monitor matched all 209 expected pricing components in its reviewed sweep. One documentation-only Mistral URL timed out after retry; its incomplete baseline was preserved until a separate successful recheck. Network failures remain visible failures. Reports distinguish price verification from reachability-only documentation checks. Price checks are point-in-time evidence, not a guarantee of future prices.

Anti-framing is not enforced by GitHub Pages response headers. Explicit cache-storage charges and time-of-use scheduling are not fully modeled; the UI discloses or blocks these cases. No missing fields were filled with guessed values, and no incomplete evidence was accepted as unchanged pricing.
